# 叶子森 · Jason Ye 个人主页

白底黑字的简约学术主页。桌面使用左侧个人信息与目录、右侧正文布局，手机自动切换为单列。英文采用 Times New Roman，中文回退到宋体；实际字体取决于设备是否安装。

原生 HTML、CSS、JavaScript，无需安装依赖或构建，可直接上传 GitHub Pages。

## 预览

双击 index.html。复制邮箱功能在本地文件页面可能受浏览器限制，发布到 HTTPS 后可用，受限时会提示手动复制。

## 发布

1. 打开 https://github.com/Jason-Yeah/jason-yeah.github.io 。
2. 点击 Add file → Upload files。
3. 上传本目录里的文件，确保 index.html 在仓库根目录，不要上传整个外层文件夹或 ZIP。
4. 提交后，进入 Settings → Pages，选择 Deploy from a branch → main → / (root)，保存。
5. 部署成功后访问 https://jason-yeah.github.io/ 。

已有旧版本时，用新版文件覆盖同名文件即可。若仍看到旧样式，可使用 Ctrl+F5 刷新。

## 编辑

- index.html：个人资料、简介、研究兴趣、论文与专利、荣誉、项目、技能和联系方式。英文名统一为 Jason Ye。
- styles.css：字体、布局、移动端与打印样式。
- script.js：复制邮箱、当前年份与目录定位状态。
- favicon.svg：黑白浏览器图标。
- og.png：黑白链接分享图。

增加论文、专利时，在相应有序列表添加 li；增加项目时，在 id="projects" 内添加 article。可以按现有条目结构编辑。
